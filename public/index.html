BEFORE YOU PRESS ANYTHING

这台机器只会烧钱。

它不产出任何东西。没有文案、没有代码、没有图片。模型输出的每一个 token 都会被立刻丢弃。你付钱，换回一个变大的数字。

只对你自己的账号使用。你需要自备 API key，费用从你自己的账单里扣。这个项目不会、也不能替你付钱。

key 只活在这个进程的内存里。不写磁盘、不进日志、不上传任何地方。刷新页面就没了，重启服务就没了。请勿在公用电脑上使用。

费用可能超出你的预期。启动前必须设置金额或时长上限，还可叠加用量和次数限制，先到先停。价格和用量存在估算误差，实际账单以服务商为准。

不要用它绕过任何配额或条款。部分服务商禁止自动化滥用行为。你对自己的账号行为负责——包括被限流、被降级、被封禁。

如果你不确定自己在做什么，请关掉这个页面。这不是一个需要"试一试"的东西。

本项目是讽刺性的工程玩具，用于观察 API 计费行为与限流机制。作者不对任何账单、账号状态或数据损失负责。MIT License，无任何担保。
