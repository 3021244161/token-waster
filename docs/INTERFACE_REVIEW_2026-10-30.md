# 界面可读性与 GitHub 问题处理

日期：2026-10-30。基础提交：7ff50b4。

## 阅读问题与调整

原版将大量中文说明和标签设为 10–11.5px，并普遍使用等宽字体；次要文字与时间戳过暗，操作按钮禁用时整体透明，放大了阅读负担。

- 正文和输入为 16px，标签与说明为 14px；中文正文和日志使用系统字体，等宽字体用于数字和标识。
- 提高次要文字亮度和行距。说明文字在深色面板上的对比度约 7.86:1。
- 减弱火焰背景，取消计数数字的发光与闪动。禁用按钮仍保留可辨识文字，键盘焦点明确可见。
- 默认收起长服务商说明，缩短策略文案，明确金额或时长必填。参数、急停和声明入口保留。
- 桌面配置区适度加宽，手机三列字段改为两列；运行数据可换行，避免省略关键统计。

## GitHub 问题

| 编号 | 修复 | 验证 |
| --- | --- | --- |
| #1 | 参数错误才尝试自适应，只有真正调整后才增加次数 | 连续 7 次临时失败后仍可降低输出上限；纯临时错误不增加调整次数 |
| #2 | 小输出额度不发送无效思考预算，合法的大额度行为保留 | 800 输出额度省略思考；128,000 输出额度保留 4,000 思考预算 |
| #3 | 文本上限贯通页面、请求校验、规划与快照；先算填充比例，再限顶 | 大窗口配 50,000 上限的输入接近 50,000；请求中的越界值被限制为 2,000,000 |
| #4 | 非美元计价要求独立兜底，时长目标直接生效，慢订阅及时断开 | 计价拒绝/接受路径、较短时长护栏和三种订阅写入情况均覆盖 |

单次文本上限包含固定指令，默认 250,000，范围 1,024–2,000,000；实际输入还受输出、图片、上下文和预算约束。上传体积只做本地粗估，大文本以可取消的分段任务准备。价格与汇率仍是静态估算，不承诺真实账单精度。
