# [P1] 上游错误回显中的敏感内容会进入状态、日志和导出报告

状态：已修复（2026-10-29）。验证方式：本地模拟与当前代码路径核验。审查日期：2026-10-29。

## 位置

src/protocols/http.js:8–12、61–64；src/engine.js 的错误处理与 report。行号以审查时工作区为准。

## 现象与证据

本地模拟服务返回 401，并在错误正文中回显一个离线测试用敏感值。最终状态的最后错误、运行日志和报告数据都包含同一完整值；验证仅输出是否包含的布尔结果。

## 原因与影响

错误对象直接拼接上游响应正文，运行错误处理又将这一消息写入状态和日志，导出报告继续沿用这些内容；未对当前运行中已知的敏感值进行脱敏。

即使本地没有记录请求头，上游正文回显仍会使敏感内容出现在界面和可分享的报告中，违背既定的信息保护边界。

## 复现步骤

1. 为本地模拟调用使用一个不具任何权限的离线占位值。
2. 模拟服务在 401 错误正文中回显该占位值。
3. 检查最终错误、日志和报告数据是否包含完整占位值。

## 修复建议

所有错误进入状态、日志或报告之前，统一清除已知敏感值及其常见编码形式；对上游错误正文采用受限字段提取和默认脱敏策略。

## 验收标准

占位敏感值出现在任意错误正文、错误路径或嵌套错误字段时，状态、日志和导出内容都不能出现其完整值。

## 修复记录

错误只取供应商的 message 字段，凭证形态的字符串打码，长度硬截断。
