# [P2] 流式空闲计时器无法取消已锁定的响应体

状态：已修复（2026-10-29）。验证方式：本地模拟与当前代码路径核验。审查日期：2026-10-29。

## 位置

src/protocols/http.js:85–97。行号以审查时工作区为准。

## 现象与证据

模拟服务发送一个保活块后保持静默。空闲时限为 40 毫秒，180 毫秒后调用仍未结束，最终需外部取消信号解除等待。

## 原因与影响

异步遍历已经锁定响应体，计时器直接调用响应体的取消方法会失败；错误被吞掉，正在等待的读取不受影响。

空闲恢复功能不生效，工作线程仍可被无数据连接占用到总超时，新增的恢复与重试逻辑也不能及时运行。

## 复现步骤

1. 用本地模拟服务发送响应头和一个保活块，然后不再发数据也不关闭连接。
2. 给协议调用设置较短空闲时限和较长总超时。
3. 空闲时限之后检查调用是否已结束。

## 修复建议

显式持有读取器并取消读取器，或通过该请求可控的取消信号终止等待；不得吞掉取消失败后继续挂起。

## 验收标准

静默连接在空闲截止后应及时返回可分类的错误，且释放连接和计时器。

## 修复记录

`readSse` 改用 `getReader()` 读取，空闲计时器可以直接 `reader.cancel()` 打断挂起的读。
